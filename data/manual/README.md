# Manual Data Seeds

These CSV files supplement automated fetchers. Raw/processed market data is gitignored; seed templates are committed.

## RBI Rates — `rbi_rates_seed.csv`

Columns: `date, repo_rate, reverse_repo_rate, tbill_91d, tbill_182d, tbill_364d, gsec_2y, gsec_10y`

Rates are expressed as percentages (e.g. `6.50` for 6.50%). The fetcher converts to decimals for BSM.

**Primary source:** [RBI DBIE](https://dbie.rbi.org.in) → Statistics → Financial Markets → Treasury Bills / Policy Rates.

**Fallback:** The repo ships `rbi_rates_seed.csv` with approximate piecewise rates for 2018–2023 when DBIE export is unavailable.

## Events Calendar — `events_calendar_seed.csv`

Columns: `date, event_type, description, rbi_rate_change_bps`

Event types: `RBI_MPC`, `UNION_BUDGET`, `US_FOMC`, `INDIA_CPI`

NSE weekly/monthly expiries are auto-generated by `events_calendar_fetcher.py`.

**Manual sources:**
- RBI MPC dates: [rbi.org.in](https://www.rbi.org.in)
- Union Budget: Ministry of Finance press releases (typically Feb 1)
- US FOMC: [federalreserve.gov](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)

Update seed files annually and re-run `make data`.
